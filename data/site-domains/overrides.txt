# Corrections to the vendored site-category lists.
#
# The upstream classes do not line up with what the label means to an analyst:
# Wikidata's university class carries the social networks, Matomo files Facebook
# under search engines, and several classes name a registry suffix as an
# organisation's official website. Editing the source files is pointless because
# scripts/refresh-domain-data.sh rewrites them, so the entries below are
# subtracted when the lists are indexed and a correction survives a refresh.
#
# One entry per line: <list> <domain>, where <list> is a file in this directory
# without its .txt, or * for every list. Blank lines and # comments are ignored.
# This file only removes. Additions belong in the hand-curated lists
# (finance, rmm, ddns, gambling), which the refresh script leaves alone.
#
# A domain that genuinely belongs to two categories is not listed here — the
# precedence in js/core/domainCategories.js decides those, and chatgpt.com
# sitting in both the AI and search lists is the intended shape.
